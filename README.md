# WeKings

Учебная конфигурация 1С: учёт performance digital-агентства (iGaming) —
клиенты-казино, веб-мастера, конверсии, взаиморасчёты, отчёты СКД.

## Тестовый стенд

Исходники сидера: `utils/ТестовыеДанные/`. Прогон — хук-механизм:
копия проекта `C:\Bases\WeKings_hook_v1` (проект + общий модуль ЗапускТестов
+ модуль управляемого приложения) загружается в базу `C:\Bases\InfoBase2`,
запускается 1cv8t ENTERPRISE — тесты выполняются при старте приложения,
результат пишется в `C:\Bases\WeKings_test_log.txt` (строки PASS/FAIL).
После прогона база перезагружается чистым проектом (`load.cmd`).
Альтернатива через внешнюю обработку: `utils\build_epf.cmd` + `utils\run_test.cmd`.

Принцип: прогон тестов воспроизводим без дублей — сидер идемпотентен
(find-or-create по ключам документов, повторный прогон не создаёт новых).
